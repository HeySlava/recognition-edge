# Recognition Edge

A web app for training Rubik's Cube **edge recognition** — memorizing which letter pair corresponds to each edge piece, an essential skill for blindfolded (BLD) solving.

## Features

- Random edge pieces shown as two colored stickers
- Answer by typing the edge's letter pair (supports EN/RU letter schemes)
- Tracks streak, accuracy, and per-edge stats
- Option to exclude buffer pieces
- Session results with timing info

## Getting Started

```bash
npm install
npm run dev      # start dev server
npm run build    # production build
```
